### 💻 Things I've Built Recently

* **[LLM Chatbot Service with Caching](https://github.com/srivanirdy)**  
  Built a containerized backend using FastAPI and Redis that caches frequent queries, lowering token costs and speeding up response times significantly.

* **[Autonomous SQL AI Agent](https://github.com/srivanirdy)**  
  An agent built with LangChain, ChatGroq, and SQLite that converts natural language requests into valid SQL queries and summarizes the resulting data.

* **[Order & Payment Microservices](https://github.com/srivanirdy)**  
  A decoupled microservices setup handling order workflows and payment processing, connected to PostgreSQL and configured with Docker Compose.
